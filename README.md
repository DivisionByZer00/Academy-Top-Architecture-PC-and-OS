#### Выполнение домашних заданий "Архитектура ПК и ОС"

## Homework 01

### Тема: "Установка Linux в виртуальной машине"

**Задание 1. Подготовка хоста и гипервизора**
1. Проверьте, что на диске хоста есть минимум 30-40 ГБ свободного места.
2. Установите VirtualBox (или другой согласованный гипервизор) с официального сайта.
3. Запишите: ОС хоста, версию гипервизора, сколько RAM у хоста.

**Задание 2. Создание VM и подключение ISO**
1. Создайте VM с именем linux-lab-<ваша_фамилия> (латиницей, без пробелов).
2. Выделите RAM: 2048-4096 МБ (по возможностям хоста).
3. Создайте виртуальный диск 20-30 ГБ, динамический.
4. Скачайте Ubuntu Desktop LTS с https://ubuntu.com/download/desktop
5. Подключите ISO к виртуальному DVD, проверьте порядок загрузки (Optical первым).
6. Запустите VM и убедитесь, что появляется экран установщика Ubuntu.

**Задание 3. Установка Linux**
1. Пройдите установку Ubuntu на виртуальный диск (не на диск хоста).
2. Создайте учебного пользователя и пароль, запишите их у себя (в отчёт пароль не пишите).
3. Дождитесь окончания установки и перезагрузите VM.
4. Отключите ISO после успешной установки (Settings -> Storage -> убрать образ с CD).
5. Войдите в систему под своим пользователем.

**Задание 4. Snapshot и проверка системы**
1. Выключите VM (Power Off).
2. Создайте snapshot с именем clean-install-done.
3. Запустите VM снова, откройте Terminal.
4. Выполните и сохраните вывод:
- whoami
- hostname
- uname -a
- lsblk
5. Убедитесь, что система загружается с виртуального диска, а не с ISO.

**Задание 4. Процессы**
1. Запустите sleep 90 в фоне.
2. Найдите PID через ps aux | grep sleep.
3. Завершите процесс через kill.
4. Проверьте, что процесса больше нет.

**Задание 5. Короткий вывод (5-7 предложений)**

## Homework 03

### Тема: "Пакеты и обновления Linux. Репозитории, зависимости, apt"

**Задание 1. Подготовка и сеть (минимум 3 действия)**
1. Проверьте сеть: ping -c 2 8.8.8.8 или apt update (если ping недоступен).
2. Создайте папку ~/homework-apt/logs.
3. Запишите в ~/homework-apt/logs/network.txt: hostname, дата, результат проверки сети.

**Задание 2. Обновление (минимум 2 команды)**
1. Выполните sudo apt update, сохраните последние 5 строк вывода.
2. Выполните apt list --upgradable | head -n 10 (если список пуст - так и запишите).
3. Ответьте: чем apt update отличается от apt upgrade? Обновляли ли вы систему командой upgrade - да/нет и почему.

**Задание 3. Установка и проверка (минимум 2 пакета)**
1. Выберите два пакета из списка: tree, jq, htop, wget (если уже стоят - выберите другие из apt search).
2. Перед установкой для каждого: apt show <пакет> - выпишите версию и одну строку Depends.
3. Установите оба: sudo apt install <пакет1> <пакет2>.
4. Проверьте: which для каждой команды и одна демонстрация работы (например, tree ~ или jq --version).

**Задание 4. Удаление (минимум 2 шага)**
1. Удалите один из установленных пакетов: sudo apt remove <пакет>.
2. Выполните sudo apt autoremove, зафиксируйте, удалялось ли что-то.
3. Проверьте dpkg -l | grep <пакет> после удаления.

**Задание 5. Короткий вывод (5-7 предложений)**    
Ответьте: что такое репозиторий своими словами, зачем смотреть зависимости, какая ошибка apt встретилась или чего вы избежали благодаря apt show.

## Homework 05

### Тема: "Загрузка ОС. BIOS/UEFI, GRUB, ядро"

**Задание 1. Карта /boot (минимум 4 пункта)**
1. ls -lh /boot
2. uname -r
3. Есть ли совпадение версии в имени файла и uname -r?
4. Сколько пар vmlinuz/initrd лежит в /boot и зачем может быть больше одной?

**Задание 2. UEFI или legacy**
1. lsblk -f - есть ли /boot/efi?
2. sudo efibootmgr или объяснение, почему недоступно
3. В настройках VM: UEFI или BIOS? Совпадает с п.1-2?

**Задание 3. Логи загрузки**
1. dmesg | head -n 25 - сохраните фрагмент
2. journalctl -b -p err --no-pager - есть ли ошибки?
3. journalctl --list-boots - сколько записей о загрузках?

**Задание 4. fstab и параметры ядра (только чтение)**
1. cat /etc/fstab | grep -v ‘^#’ - выпишите строку для / и для /boot/efi (если есть)
2. findmnt --fstab и findmnt / - совпадает ли SOURCE корня?
3. cat /proc/cmdline - есть ли root=UUID= или root=/dev/...?
4. sudo blkid | head -n 5 - сравните UUID с fstab (своими словами: совпадают / не совпадают)

**Задание 5. Симуляция диагностики (письменно)**    
Опишите, на каком этапе цепочки (POST/прошивка / GRUB / ядро+initramfs / fstab / systemd) вы бы искали причину для:
а. «No bootable medium»;
б. «Kernel panic - not syncing: VFS: Unable to mount root fs»;
в. «Welcome to emergency mode» после перезагрузки.

**Задание 6. Вывод (5-7 предложений)**    
Что из загрузки стало понятнее? Какая команда самая полезная для отчёта после перезагрузки?
